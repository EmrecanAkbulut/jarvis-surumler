# JARVIS sürümleri

JARVIS masaüstü asistanının kurulum dosyaları. Kurulu JARVIS güncellemeleri buradan kendisi indirir.
İlk kurulum için en son sürümdeki `JARVIS-<sürüm>-setup.exe` dosyasını indirip çalıştırın.
GPL lisanslı bileşenlerin (Piper TTS, espeak-ng) kaynak kodu her sürümdeki `kaynak-*.tar.gz` dosyalarındadır.
